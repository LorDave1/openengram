# speech_markers

**Status:** 💡 open for contributors. Nothing implemented yet.

## Question
Detect early language changes (pauses, vocabulary, sentence complexity) associated with cognitive decline.

## Possible data
Only openly licensed speech corpora. DementiaBank requires membership and cannot be redistributed.

## Want to lead this?
Open an issue titled "[speech_markers] proposal" with your plan, the data you'd use and its license.
Follow the rules in [CONTRIBUTING.md](../../CONTRIBUTING.md) and [SAFETY.md](../../SAFETY.md).
