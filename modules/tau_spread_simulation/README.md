# tau_spread_simulation

**Status:** 💡 open for contributors. Nothing implemented yet.

## Question
Simulate how misfolded tau protein spreads along the brain's structural network (network diffusion models on a connectome), and compare with known Braak staging / tau-PET patterns.

## Possible data
Open connectomes (check license), e.g. averaged atlases shipped with open tools; open tau-PET summaries if available.

Open an issue titled "[tau_spread_simulation] proposal" with your plan, the data you'd use and its license.
